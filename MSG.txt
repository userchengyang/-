#no_python
[错误] 未找到 Python 运行环境
  本文件夹本该自带 python 子目录，现在它不见了。
  请重新解压完整的程序包，不要只复制其中的个别文件。
  如果你是从源码自己构建的，请先双击 打包便携版.bat 生成运行环境。

#old_python
[错误] Python 版本过低，本程序需要 3.13 或更高版本。
  正常情况下程序用的是自带的 python 目录，
  走到这里说明它被替换或破坏了，请重新解压完整的程序包。

#deps_fail
[错误] 依赖安装失败
  1. 确认这台电脑能上网，且能打开 https://pypi.tuna.tsinghua.edu.cn
  2. 如果这个文件夹是自己构建的，重新双击 打包便携版.bat 再生成一次

============================================================

#build_deps_fail
[错误] 核心依赖安装失败
  1. 先确认网络能访问 pypi，浏览器打开 https://pypi.tuna.tsinghua.edu.cn 试试
  2. 如果本机 Python 是很新的版本(比如 3.14)，部分库可能还没发布对应的
     安装包，这种情况请改装 Python 3.13 后重新运行本脚本
